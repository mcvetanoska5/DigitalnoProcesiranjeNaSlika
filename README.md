This repository contains laboratory exercises and small projects developed as part of the Digital Image Processing course at the Faculty of Computer Science and Engineering (FINKI), Skopje.
The main goal of this work is to explore fundamental techniques for image enhancement, transformation, and analysis using Python.

Technologies and Tools

Programming Language: Python

Libraries: OpenCV, NumPy, Matplotlib, Pillow, Scikit-image

Environment: Jupyter Notebook / Google Colab
